## 서문

MCU가 바뀌어도 그대로 쓰는 C 프로그래밍 기법만 모았습니다. SoC 실습을 시작하기 전에 읽습니다.

### 대상 독자

| 구분 | 내용 |
|---|---|
| 전제 (알고 있어야 함) | 변수, 조건문, 반복문, 함수, 배열, 포인터 기본 문법(`*`, `&`) |
| 가정하지 않음 | 포인터를 주소 값으로 보는 시각, 구조체의 메모리 배치, 비트 단위 사고, `volatile` |
| 이 교과의 역할 | 문법 복습이 아니라, PC용 C를 읽던 눈을 임베디드용 C를 읽는 눈으로 바꾸는 것 |

### 읽는 법

- 기초편(A~D)은 주소와 메모리를 보는 시각을 만들고, 기법편(1~15)은 그 위에서 실무 기법을 우선순위대로 익힙니다.
- 한 주제는 2~3페이지입니다. 개념, 코드, 실행 결과, 함정 순서로 구성합니다.
- 레지스터 이름이나 인터럽트 진입 방식처럼 칩·코어마다 달라지는 내용은 각 실습에서 다룹니다.

## 구성과 우선순위

우선순위는 **빈도 × 파급력(틀렸을 때 디버깅 비용) × 이식성(MCU가 바뀌어도 그대로 쓰는가)**으로 정했습니다. S 6개를 먼저 익히면 실습 대부분을 소화할 수 있습니다.

### 기초편

| 장 | 주제 |
|---|---|
| A | 메모리와 주소: 바이트, 엔디안, 정렬, 주소 공간 |
| B | 포인터: 주소를 담은 변수, 산술, 형 변환, 레지스터 접근의 원형 |
| C | 구조체의 메모리 배치: 오프셋, 패딩, 레지스터 맵 구조체 |
| D | 함수 포인터와 콜백: ISR 등록, 드라이버 인터페이스 |

### 기법편 15개

| # | 기법 | 등급 | 핵심 |
|---|---|---|---|
| 1 | 비트 연산 | S | set / clear / toggle / test, 마스크와 시프트 |
| 2 | `volatile`과 메모리 매핑 레지스터 | S | `REG32` 매크로, 최적화로 읽기·쓰기가 사라지는 문제 방지 |
| 3 | 고정 폭 정수형 | S | `uint8_t`, `uint32_t`, `int` 크기 가정 금지 |
| 4 | 폴링 루프와 타임아웃 | S | 상태 비트 대기, 무한 루프 방지 |
| 5 | ISR 작성 규칙 | S | ISR(Interrupt Service Routine, 인터럽트 서비스 루틴)은 짧게, 플래그만 세우고, 공유 변수는 `volatile` |
| 6 | 초기화 순서 | S | 클록 → 핀 → 주변장치 → 인터럽트 |
| 7 | 링 버퍼 | A | Ring Buffer(원형 큐), UART 수신과 인터럽트·메인 사이 데이터 전달 |
| 8 | 상태 머신 | A | `switch` 기반 명령 파서, 프로토콜, 버튼 디바운스 |
| 9 | 논블로킹 시간 처리 | A | 타이머 틱 기반 시간 비교, `delay` 대신 사용 |
| 10 | 계층 분리 | A | HAL(Hardware Abstraction Layer, 하드웨어 추상 계층)·드라이버·응용, CPU 종속 파일 격리 |
| 11 | 임계 구역 보호 | A | Critical Section, 인터럽트 비활성화로 공유 데이터와 읽기-수정-쓰기 경합 방지 |
| 12 | 구조체·비트필드·패딩 | B | 레지스터 맵을 구조체로 덮어씌우기 |
| 13 | 링커 스크립트와 메모리 배치 | B | `.text`, `.data`, `.bss`, 스타트업 코드 |
| 14 | 정적 메모리 할당 | B | `malloc` 회피, 단편화 방지 |
| 15 | 방어적 코딩 | B | `assert`, 에러 코드 규약, 워치독(Watchdog, 감시 타이머) |

> **등급** S 필수(눈 감고 작성) · A 핵심(패턴으로 암기) · B 확장(필요할 때 참조)
