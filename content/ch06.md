## 비트 연산: 켜고, 끄고, 뒤집고, 검사하기

**S등급** 레지스터 제어는 대부분 비트 하나를 바꾸는 일입니다. 나머지 비트는 건드리지 않고 원하는 비트만 바꾸는 네 가지 동작을 외워 둡니다.

### 연산자

| 연산자 | 동작 | 주로 쓰는 곳 |
|---|---|---|
| `&` | 두 비트가 모두 1일 때만 1 | 비트 검사, 필요한 비트만 남기기(마스킹) |
| `\|` | 하나라도 1이면 1 | 비트 켜기 |
| `^` | 서로 다르면 1 | 비트 뒤집기 |
| `~` | 모든 비트를 0과 1 반전 | 끌 비트를 만드는 마스크 |
| `<<` | 왼쪽으로 n칸 이동, 오른쪽은 0으로 채움 | 비트 위치 만들기 |
| `>>` | 오른쪽으로 n칸 이동. 부호 없는 형은 왼쪽을 0으로 채움 | 필드 꺼내기 |

### 네 가지 기본 동작

| 동작 | 식 | 설명 |
|---|---|---|
| 켜기 (set) | `x \|= MASK;` | MASK의 1인 비트만 1로 만들고 나머지는 그대로 |
| 끄기 (clear) | `x &= ~MASK;` | MASK의 1인 비트만 0으로 만들고 나머지는 그대로 |
| 뒤집기 (toggle) | `x ^= MASK;` | MASK의 1인 비트만 반전 |
| 검사 (test) | `(x & MASK) != 0u` | MASK의 비트 중 하나라도 1이면 참 |

**코드 1-1 · 비트 켜기, 끄기, 뒤집기, 검사** · 파일: `src/test_bits.c` · 검증: PC(gcc) 컴파일·실행 통과, 보드 미검증

```c
/* 1-1. 비트 켜기·끄기·뒤집기·검사 */
#define BIT(n)          (1u << (n))
#define BITS_SET(x, m)  ((x) |=  (m))
#define BITS_CLR(x, m)  ((x) &= ~(m))
#define BITS_TOG(x, m)  ((x) ^=  (m))
#define BITS_TST(x, m)  (((x) & (m)) != 0u)

static void demo_bits(void)
{
    uint32_t x = 0u;

    BITS_SET(x, BIT(0) | BIT(3));
    printf("[1-1] set(0,3) : x=0x%02X\n", (unsigned)x);

    BITS_CLR(x, BIT(0));
    printf("      clr(0)   : x=0x%02X\n", (unsigned)x);

    BITS_TOG(x, BIT(1) | BIT(3));
    printf("      tog(1,3) : x=0x%02X\n", (unsigned)x);

    printf("      tst(1)=%d tst(3)=%d\n", BITS_TST(x, BIT(1)), BITS_TST(x, BIT(3)));
}
```

**실행 결과 (PC에서 실제 실행)**

```text
[1-1] set(0,3) : x=0x09
      clr(0)   : x=0x08
      tog(1,3) : x=0x02
      tst(1)=1 tst(3)=0
```

`BIT(n)`은 n번 비트만 1인 값을 만듭니다. 0번이 가장 낮은 자리(LSB)입니다. 여러 비트는 `BIT(0) | BIT(3)`처럼 `|`로 묶어 한 번에 다룹니다.

### 정수 승격과 부호

**코드 1-2 · ~ 연산과 BIT(31)** · 파일: `src/test_bits.c` · 검증: PC(gcc) 컴파일·실행 통과, 보드 미검증

```c
/* 1-2. 정수 승격과 부호 */
static void demo_promote(void)
{
    uint8_t m = 0x01u;
    int inv = ~m;                       /* m이 int로 승격된 뒤에 반전된다 */

    printf("[1-2] ~m = 0x%X, (uint8_t)~m = 0x%02X, ~m == 0xFE ? %s\n",
           (unsigned)inv, (unsigned)(uint8_t)inv, (inv == 0xFE) ? "참" : "거짓");
    printf("      BIT(31) = 0x%08X\n", (unsigned)BIT(31));
}
```

**실행 결과 (PC에서 실제 실행)**

```text
[1-2] ~m = 0xFFFFFFFE, (uint8_t)~m = 0xFE, ~m == 0xFE ? 거짓
      BIT(31) = 0x80000000
```

`uint8_t`, `uint16_t`는 연산 전에 `int`로 승격되므로 `~m`은 8비트가 아니라 32비트 값입니다. 8비트 결과가 필요하면 `(uint8_t)`로 되돌려 비교합니다. 컴파일러가 이런 비교에 경고(`-Wsign-compare`)를 내는 이유입니다.

> **함정** 비트 마스크에는 `1`이 아니라 `1u`를 씁니다. 부호 있는 `1 << 31`은 정의되지 않은 동작입니다. 시프트 폭이 형의 비트 수 이상인 경우(`1u << 32`)도 정의되지 않습니다.

## 여러 비트 필드와 읽기-수정-쓰기

레지스터는 여러 비트가 한 묶음으로 의미를 가지는 필드로 나뉘어 있습니다. 필드의 위치(shift)와 폭(width)만 알면 꺼내고 바꾸는 식이 정해집니다.

{{svg:figures/ch06_fig01.svg|예시용 가상 CTRL 레지스터. 폭은 비트 수에 비례합니다.}}

| 동작 | 식 | 설명 |
|---|---|---|
| 필드 마스크 | `((1u << width) - 1u) << shift` | 필드 자리만 1인 값. width가 32 미만일 때만 유효 |
| 필드 읽기 | `(x >> shift) & ((1u << width) - 1u)` | 아래로 내린 뒤 필드 폭만 남깁니다. |
| 필드 쓰기 | `(x & ~mask) \| ((v << shift) & mask)` | 필드를 지우고 새 값을 넣습니다. 다른 비트는 그대로 |

**코드 1-3 · 필드 읽기·쓰기와 읽기-수정-쓰기** · 파일: `src/test_bits.c` · 검증: PC(gcc) 컴파일·실행 통과, 보드 미검증

```c
/* 1-3. 여러 비트 필드 읽기·쓰기 */
#define FIELD_MASK(shift, width)  (((1u << (width)) - 1u) << (shift))
#define FIELD_GET(x, shift, width)  (((x) >> (shift)) & ((1u << (width)) - 1u))
#define FIELD_SET(x, shift, width, v) \
    (((x) & ~FIELD_MASK(shift, width)) | (((uint32_t)(v) << (shift)) & FIELD_MASK(shift, width)))

#define CTRL_ENABLE_SHIFT  0     /* [0]    ENABLE */
#define CTRL_MODE_SHIFT    1     /* [2:1]  MODE   */
#define CTRL_MODE_WIDTH    2
#define CTRL_DIV_SHIFT     8     /* [15:8] DIV    */
#define CTRL_DIV_WIDTH     8

static uint32_t fake_ctrl;       /* 가상 CTRL 레지스터 */

static void demo_field(void)
{
    uint32_t v = fake_ctrl;                                        /* 읽고 */
    v = FIELD_SET(v, CTRL_MODE_SHIFT, CTRL_MODE_WIDTH, 2u);        /* 필드만 바꾸고 */
    v = FIELD_SET(v, CTRL_DIV_SHIFT,  CTRL_DIV_WIDTH,  0x64u);
    v |= BIT(CTRL_ENABLE_SHIFT);
    fake_ctrl = v;                                                 /* 한 번에 쓴다 */
    printf("[1-3] CTRL=0x%04X MODE=%u DIV=0x%02X\n", (unsigned)fake_ctrl,
           (unsigned)FIELD_GET(fake_ctrl, CTRL_MODE_SHIFT, CTRL_MODE_WIDTH),
           (unsigned)FIELD_GET(fake_ctrl, CTRL_DIV_SHIFT, CTRL_DIV_WIDTH));

    v = fake_ctrl;
    v = FIELD_SET(v, CTRL_MODE_SHIFT, CTRL_MODE_WIDTH, 1u);        /* MODE만 2 -> 1 */
    fake_ctrl = v;
    printf("      MODE를 1로: CTRL=0x%04X (ENABLE, DIV 유지)\n", (unsigned)fake_ctrl);

    fake_ctrl = FIELD_SET(0u, CTRL_MODE_SHIFT, CTRL_MODE_WIDTH, 3u);   /* 읽지 않고 바로 쓰면 */
    printf("      읽지 않고 MODE만 쓰면: CTRL=0x%04X (DIV, ENABLE이 사라짐)\n", (unsigned)fake_ctrl);
}
```

**실행 결과 (PC에서 실제 실행)**

```text
[1-3] CTRL=0x6405 MODE=2 DIV=0x64
      MODE를 1로: CTRL=0x6403 (ENABLE, DIV 유지)
      읽지 않고 MODE만 쓰면: CTRL=0x0006 (DIV, ENABLE이 사라짐)
```

레지스터의 일부 필드만 바꿀 때는 **읽고, 필드만 바꾸고, 한 번에 쓰는** 순서를 지킵니다. 마지막 줄처럼 읽지 않고 바로 쓰면 같은 레지스터의 다른 필드가 모두 새 값으로 덮어씌워집니다.

### 자주 겪는 문제

| 증상 | 원인 | 조치 |
|---|---|---|
| `x & MASK == 0`이 항상 이상하게 동작 | `==`가 `&`보다 먼저 계산됨(연산자 우선순위) | `(x & MASK) == 0u`처럼 괄호를 칩니다. |
| 끄려던 비트 말고 다른 비트도 꺼짐 | `x &= MASK`처럼 `~`를 빠뜨림 | 끌 때는 항상 `&= ~MASK`입니다. |
| 필드 하나를 바꿨는데 다른 설정이 사라짐 | 읽지 않고 레지스터에 바로 씀 | 읽기-수정-쓰기 순서를 지킵니다. |
| 상태 비트를 `\|=`나 `&=`로 바꿨더니 다른 비트가 변함 | 읽기-수정-쓰기는 읽은 값을 그대로 다시 쓰므로, 1을 써서 지우는 비트(Write-1-to-Clear)가 같이 지워질 수 있음 | 해당 비트의 동작을 데이터시트로 확인합니다. 자세한 내용은 기법 2와 11에서 다룹니다. |
| 값이 예상보다 크게 나옴 | `uint8_t` 값이 `int`로 승격되어 연산 결과에 상위 비트가 남음 | 결과를 `(uint8_t)`로 되돌리고 마스크를 씌웁니다. |
